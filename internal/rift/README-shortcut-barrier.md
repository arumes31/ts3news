# Breakable shortcut barriers

Each Hidden Alcoves second tier has a wooden barrier across its central approach.
The player may walk around above/below immediately, or break the barrier for a
shorter direct route while carrying the relic. Barriers stand in the open central
passage with clearance from existing alcove cover and jump routes.

The existing wooden-cover system supplies 60 health, melee/projectile damage,
impact/break sounds, saved destruction, blocking while intact and rubble when
broken. Breaking terrain gives no enemy kill or loot credit. An optional shortcut
flag adds BREAK FOR SHORTCUT / SHORTCUT OPEN labels. Normal durability and minimap
cover markers remain. Older saved cover without this flag behaves unchanged.

Tests walk both bypasses in every affected region, break the actual authored
barrier with melee, reload the run and cross the direct route. Full prop perimeter,
low-cover vault and enemy pursuit checks remain enabled. Browser checks show both
states in both motion settings; the existing real keyboard cover journey verifies
hit/break audio, reload, traversal and reachable loot.
